# LOL 프로토타입

2D 탑뷰 MOBA (HTML5 Canvas + JavaScript, 빌드 도구 없음). 기본 게임 위에 챔피언을 하나씩 추가하고 있습니다.

## 실행
- `index.html` 더블클릭 (크롬/엣지 권장), 또는
- 이 폴더에서 `python -m http.server 8123` 실행 후 http://localhost:8123 접속

## 챔피언
| 챔피언 | 역할 | 상태 |
|---|---|---|
| ⚙️ 오리아나 | 미드 · 마법사 | 패시브 + Q/W/E/R 구현 |
| ⚔ 기본 유닛 | 테스트용 | 스킬 없음 |

### 오리아나
수치 출처: [나무위키 「오리아나(리그 오브 레전드)」](https://namu.wiki/w/%EC%98%A4%EB%A6%AC%EC%95%84%EB%82%98(%EB%A6%AC%EA%B7%B8%20%EC%98%A4%EB%B8%8C%20%EB%A0%88%EC%A0%84%EB%93%9C)).
체력/마나 재생은 문서의 5초당 수치를 초당으로 바꿔 적용했습니다.

| 스킬 | 내용 |
|---|---|
| 패시브 · 시계태엽 감기 | 기본 공격에 10~50(+주문력 15%) 마법 피해. 4초 안에 같은 대상 재공격 시 15%씩, 최대 2중첩 |
| Q · 명령: 공격 | 구체를 최대 825 거리로 발사, 경로와 도착 지점 적에게 60~180(+55%) 마법 피해, 두 번째 적부터 30% 감소 · 마나 35 · 7/6/5/4/3초 |
| W · 명령: 불협화음 | 구체 주변 250 범위에 70~230(+80%) 마법 피해, 3초 자기장(적 20~40% 둔화, 아군 같은 수치 가속, 2초에 걸쳐 감소) · 마나 60~80 · 7초 |
| E · 명령: 보호 | 구체를 아군(없으면 자신)에게 보내 2.5초 보호막 60~220(+45%), 경로의 적에게 60~180(+30%) 피해. 구체가 붙은 아군은 방어력·마법 저항력 +6~30 · 마나 60 · 9초 |
| R · 명령: 충격파 | 0.75초 후 구체 주변 400 범위에 225/350/475(+110%) 마법 피해, 적을 구체 쪽으로 끌어당김 · 마나 100 · 110/95/80초 |

- 구체는 오리아나에게서 1120 이상 떨어지면 돌아오고, 바닥의 구체에 다가가면 다시 줍습니다.
- 구체가 날아가는 중에 누른 W/R은 구체가 도착한 뒤 발동합니다.
- 문서에 없어서 임의로 정한 값: 패시브가 3레벨마다 오르는 구간, Q 도착 범위 175, 구체 판정 폭 80, E 구체 속도 1850, R 끌어당김 거리 340, 구체 줍는 거리 70.

## 조작
| 키 | 동작 |
|---|---|
| 우클릭 (누르고 있기 가능) | 이동 / 대상 공격 |
| A + 좌클릭 | 공격 이동 |
| Q / W / E / R | 스킬 (마우스 위치로 바로 시전) |
| Shift + Q / W / E / R | 스킬 레벨 올리기 (HUD의 + 버튼도 가능) |
| S | 정지 |
| D / F | 회복 / 점멸 |
| B | 귀환 (8초) |
| P | 상점 (우물 근처에서만 구매) |
| 1~6 | 아이템 사용 (물약) |
| Space / Y | 카메라 중앙 / 카메라 고정 전환 |
| 휠, 화면 가장자리, 방향키 | 확대·축소, 카메라 이동 |
| 미니맵 좌클릭 / 우클릭 | 카메라 이동 / 이동 명령 |
| Esc | 일시정지 |

스킬 아이콘에 마우스를 올리면 설명과 범위가 표시됩니다.

## 구현된 것
- 3라인 맵 + 강 + 정글 4구역, 바론/용 둥지, 전장의 안개(시야)
- 포탑(외곽→내부→억제기→넥서스 순서 보호), 억제기(4분 후 재생성), 넥서스, 우물 레이저
- 미니언 웨이브 (30초마다, 3웨이브마다 공성 미니언, 억제기 파괴 시 슈퍼 미니언, 시간에 따른 강화)
- 정글 캠프 12개 + 용/공허의 군주, 버프(푸른·붉은 기운, 용 중첩, 군주의 권능)
- 챔피언 공통: 레벨 1~18, 스킬 포인트(R은 6/11/16레벨), 마나, 주문력, 스킬 가속, 마법 관통력
- 전투 효과: 마법 피해, 보호막, 둔화/가속(감쇠), 에어본·끌어당김
- 챔피언 선택 화면, HUD(스킬 칸·쿨다운·툴팁), 미니맵, 상점(챔피언 추천 아이템), 승리/패배 화면

## 파일 구조
```
js/config.js            수치 설정 (유닛/구조물/몬스터/버프 스탯)
js/map.js               맵 지형, 구조물 배치, 충돌 격자, A* 길찾기
js/entities.js          Unit 기본 클래스(상태 효과 포함), 미니언, 정글 몬스터, 투사체
js/structures.js        포탑, 억제기, 넥서스, 우물
js/hero.js              챔피언 공통 기반 (명령/공격/레벨/마나/스킬 포인트/주문)
js/champions/orianna.js 오리아나 (스탯, 스킬 데이터, 구체 로직, 그리기)
js/items.js             아이템 데이터, 상점 로직
js/game.js              게임 규칙 (웨이브, 피해 계산, 시야, 사망 처리, 승패)
js/input.js             마우스/키보드/카메라
js/render.js            캔버스 그리기, 안개, 체력바, 미니맵
js/ui.js                HUD, 챔피언 선택, 상점 창, 툴팁
```

## 챔피언 추가 방법
1. `js/champions/<이름>.js`를 만들고 `HERO_BASE`와 같은 형식의 스탯 객체를 정의합니다 (`id`, `name`, `role`, `icon`, `mana` 등).
2. 스킬 데이터 객체를 만듭니다: `P`(패시브)와 `Q/W/E/R` 각각 `name`, `icon`, `maxLvl`, `cost[]`, `cd[]`, `desc(hero, lvl)`.
3. `Hero`를 상속한 클래스에서 `abilityDefs`를 지정하고 `castQ/castW/castE/castR(lvl, x, y, hoverUnit)`을 구현합니다. 필요하면 `championTick`, `onAttackHit`, `onDeathHook`, `drawBody/drawGround/drawOver`를 덮어씁니다.
4. 파일 끝에서 `CHAMPIONS.<id> = { base, create }`로 등록하고, `index.html`에 `hero.js` 다음 순서로 스크립트를 추가합니다.
