# LOL 프로토타입

2D 탑뷰 MOBA (HTML5 Canvas + JavaScript, 빌드 도구 없음). 기본 게임 위에 챔피언과 시스템을 하나씩 추가하고 있습니다.

웹사이트: https://yeonny3209.github.io/lol-prototype/

## 실행
- 위 웹사이트에 접속하거나
- `index.html` 더블클릭 (크롬/엣지 권장), 또는
- 이 폴더에서 `python -m http.server 8123` 실행 후 http://localhost:8123 접속

아이템·룬·주문 아이콘은 라이엇 Data Dragon CDN에서 불러오므로 인터넷 연결이 필요합니다 (없으면 글자로 대신 표시).

## 시작 화면
- **챔피언** 선택 → **포지션(역할군 퀘스트)** → **소환사 주문 2개** → **룬 페이지** 순서로 고릅니다.
- `추천 룬 적용` / `추천 주문 적용` 버튼으로 챔피언별 추천 구성을 불러옵니다.
- 고른 구성은 챔피언별로 브라우저에 저장됩니다.
- **조작 방식**(클래식 / WASD)을 고릅니다. 게임 중 일시정지 화면에서도 바꿀 수 있습니다.
- **연습 규칙** (기본 켜짐): 아직 적 챔피언이 없어서, '챔피언 대상' 효과(정복자·감전·점화·치유 감소 등)를 미니언·몬스터에게도 적용합니다.

## 1대1 온라인 (친구와 대결)
1. 두 사람 모두 웹사이트에 접속해 시작 화면 위쪽의 **1대1 온라인** 탭을 누릅니다.
2. 한 사람이 **방 만들기**를 누르고, 화면에 나온 **방 코드 5자리**를 친구에게 알려 줍니다. 방장은 **블루 팀**입니다.
3. 친구는 코드를 입력하고 **참가**를 누릅니다. 참가자는 **레드 팀**입니다.
4. 각자 챔피언·포지션·소환사 주문·룬을 고르고, 참가자가 **준비 완료**를 누르면 방장이 **대결 시작**을 누릅니다.
5. 규칙은 협곡 전체: 3라인·정글을 모두 쓰고 **상대 넥서스를 파괴하면 승리**합니다. 상대가 나가거나 연결이 끊겨도 남은 쪽이 승리합니다.

- **처치 보상**: 챔피언 처치 300골드, 선취점 +100골드, 처치 경험치(상대 레벨 기준, 추정값). 포탑·미니언이 마무리해도 최근 10초 안에 피해를 준 챔피언이 처치를 가져갑니다.
- 1대1에서는 **연습 규칙이 꺼지고**, 정복자·점화·치유 감소 같은 '챔피언 대상' 효과가 상대 챔피언에게만 적용됩니다.
- Esc 메뉴를 열어도 게임은 멈추지 않습니다. 대결 중에 나가면 패배로 처리됩니다.
- 화면 오른쪽 위에 핑과 연결 상태가 표시됩니다.

### 연결 방식
- 서버 없이 **P2P(WebRTC)** 로 직접 연결합니다. 방을 찾을 때만 [PeerJS](https://peerjs.com/) 공개 연결 서버를 쓰고, 직접 연결이 막히면 PeerJS 공개 중계(TURN) 서버를 거칩니다. 라이브러리는 `js/vendor/peerjs.min.js` (1.5.5, MIT 라이선스)에 들어 있습니다.
- **락스텝 동기화**: 두 컴퓨터가 같은 시드로 같은 게임을 만들고, 50ms마다 양쪽 입력을 모아 똑같은 순서로 실행합니다. 내 입력은 150ms 뒤에 실행되어 조작이 조금 늦게 반응합니다.
- 1초마다 두 게임 상태를 비교하고, 어긋나면 "동기화 오류"를 표시합니다.

### 알아둘 점
- 회사·학교·일부 모바일 네트워크는 P2P 연결을 막아서 참가가 안 될 수 있습니다. 공개 연결·중계 서버가 점검 중일 때도 연결이 안 됩니다.
- 두 사람 모두 같은 버전이어야 합니다. 사이트가 업데이트됐다면 둘 다 새로고침(Ctrl+F5)하세요.
- 한쪽 인터넷이 느리거나 끊기면 두 화면 모두 잠깐 멈춥니다. 재접속 기능은 아직 없습니다.
- 크롬·엣지처럼 같은 계열 브라우저를 쓰는 것을 권장합니다 (브라우저 계산 차이로 인한 동기화 오류 방지).

## 아이템 (패치 16.18.1)
- **데이터**: 라이엇 [Data Dragon](https://developer.riotgames.com/docs/lol#data-dragon) `16.18.1 / ko_KR`의 소환사의 협곡 아이템 전체 — 시작·기본·서사급·전설급·신발(3단계 포함)·소모품·장신구·정글·서포터, 그리고 변신 아이템(무라마나, 대천사의 포옹, 종말의 겨울, 악곡의 왕관 등)까지 223개.
- 이름·가격·조합비·판매가·조합법·스탯은 데이터에서 자동으로 가져옵니다. `node tools/build-data.js`로 최신 패치로 다시 만들 수 있습니다.
- **효과**는 아이템마다 직접 구현했습니다 (`js/effects*.js`, `js/data/item_effects.js`). 주문 검, 쪼개기, 생명선, 마나순환, 영광, 불사르기, 충전 공격, 보호막, 사용 효과 등. 공개 데이터에 수치가 없는 효과는 설명에 `※수치 일부 추정`으로 표시했습니다.
- **상점**: 카테고리 탭·검색·챔피언 추천 탭, 조합 트리(가진 하위 아이템 초록 표시), 상위 아이템, 가진 재료만큼 가격 할인, 우클릭 즉시 구매, 판매.
- 같은 계열(신발·생명선·히드라·마나순환·수은·정글·서포터 등) 1개 제한, 같은 전설급 중복 금지.
- **아직 발동하지 않는 효과**: 아군 챔피언이나 적 스킬이 필요한 효과(기사의 맹세, 미카엘의 축복, 불타는 향로, 주문 방어막 등)는 설명에 표시만 되어 있습니다.

## 룬
- 5개 트리의 모든 룬(핵심 룬 포함 62개)과 능력치 파편 3줄을 룬 설명 기준으로 구현했습니다.
- 규칙: 주 트리 핵심 룬 + 줄마다 1개, 보조 트리는 서로 다른 줄에서 2개.
- 추천 룬: 오리아나 = 신비로운 유성 / 리 신 = 정복자 / 기본 유닛 = 치명적 속도.
- 적 와드·현상금 등 적 챔피언이 필요한 룬은 설명에 표시만 되어 있습니다.

## 소환사 주문
점멸, 순간이동(10분부터 강력 순간이동), 점화, 회복, 방어막, 탈진, 유체화, 정화, 강타(2회 충전, 강화·원시 단계). 수치는 LoL 공식 위키 기준이며 회복·유체화·탈진 일부 수치는 확인하지 못해 추정입니다.

## 챔피언 추가 방법
1. `js/champions/<이름>.js`에 스탯 객체(`id`, `name`, `role`, `resource`, `recommended`, `recSpells` 등)를 정의합니다.
2. 스킬 데이터: `P`와 `Q/W/E/R` 각각 `name`, `icon`, `maxLvl`, `cost[]`, `cd[]`, `desc(hero, lvl)`.
3. `Hero`를 상속해 `castQ~castR(lvl, x, y, hover, recast)`를 구현합니다. 2단 스킬은 `abilityRecast(key)`로 재시전 조건을 알려 줍니다. 피해는 `game.dealDamage(this, t, amount, { type, ability: true, ult })`로 줘야 아이템·룬 효과가 발동합니다.
4. `CHAMPIONS.<id>`로 등록하고 `index.html`에 스크립트를 추가, `RECOMMENDED_RUNES`에 추천 룬을 넣습니다.

### 1대1 동기화를 깨지 않으려면
- 게임 로직에서는 `Math.random()` 대신 `rng()` / `srand(a, b)`를 씁니다 (`rand`는 화면 효과 전용).
- 게임 로직에서 `Math.sin/cos/atan2/hypot`을 쓰지 않습니다. 방향은 `dx / Math.sqrt(dx*dx + dy*dy)`처럼 계산하고, 고정 방향이 필요하면 `DIR16`을 씁니다. `facing`은 그리기 전용입니다.
- `game.player`(내 화면의 챔피언)에 따라 게임 상태가 달라지면 안 됩니다. 안내 문구·카메라·UI만 다르게 할 수 있습니다.
- 플레이어 조작은 직접 호출하지 말고 `Cmd.send({ k: ... })`로 보냅니다.
